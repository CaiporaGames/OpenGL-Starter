Here’s a roadmap for creating a simplified version for your engine:
1. Model Editor UI
- Use a GUI framework (e.g. Dear ImGui, Qt, or SDL)
- Allow users to place and transform primitive shapes (cubes, planes)
- Add basic mesh editing (vertex move, face extrude)
2. Texture Painting
- Implement a UV viewer and 2D texture editor
- Support painting directly on the 3D model
- Load/save textures (PNG, BMP)
3. Bone Rigging
- Let users define bones and parent-child relationships
- Assign mesh parts to bones
- Visualize bone hierarchy and influence zones
4. Animation Timeline
- Create a timeline UI with keyframes
- Support position, rotation, and scale animations
- Interpolate between keyframes (linear or cubic)
5. Export Format
- Define a custom format (e.g. .mymodel) or use glTF
- Include mesh, texture, bone, and animation data
- Make it easy to load in your engine

GUI = Dear ImGui, Qt, Nuklear;
3D Rendering = OpenGL, Vulkan, DirectX
Texture Editing = stb_image, ImGui canvas
File I/O = JSON, glTF, or custom format
Animation System = Custom keyframe interpolator

🧪 Start Small
You don’t need to build everything at once. Start with:
- A cube-based model editor
- Texture loading and painting
- Basic bone rigging and animation playback
Once that’s working, you can expand into more advanced mesh editing and export formats.
